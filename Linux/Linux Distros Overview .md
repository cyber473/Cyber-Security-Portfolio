
# 🐧 Linux Distros Overview

## 📌 Overview

A Linux Distribution (Distro) is a complete operating system built on the Linux kernel. It includes the kernel, system tools, software, and a package manager.

---

## 🎯 What is it?

A Linux Distro is a version of Linux designed for different purposes like desktop use, servers, development, and cybersecurity.

### Common Linux Distros

* Ubuntu
* Debian
* Kali Linux
* Parrot OS
* Fedora
* Arch Linux

---

## ❓ Why is it Needed?

* Provides a complete operating system.
* Manages hardware and software.
* Offers security and stability.
* Used in servers and cybersecurity.

---

## ⚙️ How Does it Work?

1. Linux Kernel starts.
2. System services load.
3. User logs in.
4. Applications run using system resources.

---

## 🏠 Real Life Example

Think of the Linux Kernel as a **car engine**.

Different Linux Distros (Ubuntu, Kali, Debian) are different **car models** built on the same engine.

---

## 🛠 Practical Demo

```bash
cat /etc/os-release
uname -r
hostnamectl
```

## 💻 Kali Linux Commands

```bash
# Show Linux Distribution
cat /etc/os-release

# Show Kernel Version
uname -r

# Show System Information
hostnamectl

# Show Logged-in User
whoami

# Show Current Directory
pwd
```
